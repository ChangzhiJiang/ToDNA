# Third-party notices

Earlier repository revisions included a PyTorch port of SeqProp's per-base normalization, identified in its original docstring by reference commit `61677a2bc469257b95231fd5f280f7eff2fb0b35`. That comparison implementation has been removed from the current tree. Its MIT license notice remains in `third_party/seqprop_LICENSE` for attribution of the historical source.

Evo2/Vortex, PyTorch, gReLU, and Enformer are external dependencies. Ledidi was an external dependency of the removed comparison implementation. Their upstream implementations and model weights are not bundled. Their separate licensing and model/data conditions continue to apply.

No project-wide license has been assigned to the original ToDNA code by the packaging process. The project owner should add the chosen license and accurate attribution before announcing an open-source release.
